# Assessment (as received from Incubyte)

Goal: Build employee salary management software for an organization with 10,000 employees.

User persona: HR Manager of the org.

Problem statement: ACME org's HR team manages salary data for 10,000 employees across multiple countries in Excel, which is tedious. The HR manager should manage salary data via web-based software and be able to answer questions about how the org pays people.

Requirements: write a one-page requirements document before building (goal, scope & features, what is deliberately left out and why).

Technical constraints: end-to-end software (backend + UI). Backend in the language of the role (TypeScript), relational DB (e.g. SQLite). UI in React/Next.js with a component library. Seed script with 10,000 employees. Fully functional deployed software and a video demo.

Development approach: agentic AI tools, high code quality, meaningful fast deterministic unit tests, incremental commits, and artifacts (requirements, design notes, architecture diagrams, AI prompts, trade-offs, performance considerations).

Submission: Git repository link, replied to the assessment email.
